# Дорожная карта

Шесть фаз. Каждая закрывается отдельной сессией.

## Фаза 0 — подготовка (1 сессия)

- инициализировать git, создать `.gitignore`, первый коммит "research baseline",
- ответить на P0-вопросы из [07-open-questions.md](07-open-questions.md),
- поставить poppler/mupdf или решить альтернативу,
- отделить PDF-источник в свой репо/bucket вне основного репозитория.

**Выход**: чистый рабочий репозиторий, ясные ответы на критические вопросы.

## Фаза 1 — полный парс ReadyMag (1-2 сессии)

- расширить `scripts/build-parse-1.mjs` на все 15 страниц,
- сохранить `content/readymag/{slug}.json` + `assets/{slug}/*` для каждой,
- `scripts/process-pdf.mjs`: разрезать 600 MB PDF на страницы, извлечь изображения, превью,
- сравнить картинки из CDN с картинками из PDF, выбрать лучший источник для каждой,
- зеркалировать 10 PDF-каталогов с lingvoeast.ru локально.

**Выход**: полный архив контента в репозитории, независимый от ReadyMag CDN и lingvoeast.

## Фаза 2 — оригиналы фотографий (1 сессия + переписка с Сергеем)

- получить high-res оригиналы (или их подмножество, что Сергей готов отдать),
- залить в `public/images/*/original/` (или R2),
- запустить `scripts/process-images.mjs` → `derived/`,
- сгенерировать `manifest.json` с blur placeholder и размерами.

**Выход**: production-ready ассеты.

## Фаза 3 — каркас нового сайта (1-2 сессии)

- инициализировать Astro проект (или Next, по результатам обсуждения),
- настроить TypeScript, Tailwind, MDX, sharp/astro:assets,
- сделать layout, шапку, подвал, основные компоненты (`<Gallery>`, `<Lightbox>`, `<YouTubeEmbed>`),
- собрать первую страницу `/retro/` end-to-end.

**Выход**: одна реальная страница нового сайта работает локально и визуально воспроизводит ReadyMag-оригинал, но в новом стеке.

## Фаза 4 — наполнение контентом (2-3 сессии)

- перенести оставшиеся 9 проектов из `content/readymag/*.json` в MDX,
- About / CV / выставки / коллекции,
- Books (с локальными PDF),
- Links, Contacts.
- Playwright-регрессии: автоматические скриншоты всех страниц на 1440 и 380.

**Выход**: полностью наполненный сайт, готовый к ревью.

## Фаза 5 — деплой и cutover (1 сессия)

- настроить Cloudflare Pages, R2 bucket для оригиналов,
- DNS на Cloudflare,
- redirects для старых URL,
- финальный QA: mobile / desktop / lighthouse / accessibility,
- переключить домен с ReadyMag на Cloudflare Pages,
- 301 со старых ReadyMag-маршрутов на новые,
- объявить Сергею.

**Выход**: production sergeysapozhnikov.ru на новом стеке.

## Фаза 6 — поддержка

- регулярно: новые проекты по мере появления (через PR в репо),
- раз в полгода: обновить зависимости, прогнать lighthouse, обновить screenshot-baseline,
- добавлять новые галереи/выставки по запросу.

## Параллельные ветки (опционально)

- **Контактная форма** через Cloudflare Worker + Resend.
- **Decap CMS** для редактирования Сергеем без git.
- **Печатная версия каждого проекта** (CSS @media print + опциональный экспорт PDF через playwright).
- **Лента "Recent" с черновиками** до полноценной выставки.

## Что готово прямо сейчас

- парсер для 2 страниц,

- список открытых вопросов.

Ничто не пропадёт зря — это уже фундамент Фазы 1.
