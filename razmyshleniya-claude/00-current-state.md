# Текущее состояние репозитория

## Что уже сделано

1. **Research-слой** в `docs/`:
   - профиль Сергея (биография, проекты, выставки, коллекции),
   - инвентарь текущего сайта (15 страниц, 424 изображения, 10 видео),
   - внешние ссылки (галереи, институции, пресса),
   - техническая стратегия парсинга ReadyMag.

2. **Пробный парс двух страниц** (`/` и `/retro/`) в `parse-1/`:
   - оригинальный HTML страницы и `HtmlSnippet` ReadyMag → `source/`,
   - тексты + структурированный JSON → `content/`,
   - 21 ассет (~13 MB) → `assets/`,
   - ручная статическая локальная сборка → `site/`,
   - скриншоты live и локальной сборки на 1440 и 380 → `screenshots/`,
   - `assets-manifest.json` и `download-assets.curl`.

3. **Парсер** `scripts/build-parse-1.mjs` (~9 KB) — node CLI, который и собрал `parse-1/`. Его нужно расширить на остальные 13 страниц.

4. **PDF-экспорт** ReadyMag в `redymag-pdf-site2020/`: 15 страниц, ~600 MB, сделан через `pdf-lib` (видно из metadata).

## Что можно использовать как фундамент

- `parse-1/content/*.json` — формат уже выглядит достаточным для миграции в MDX/JSON-based contents.
- Парсер `build-parse-1.mjs` — переиспользовать, добавить флаг `--pages` или прогнать по списку из `sitemap.xml`.
- `__RM_PROPS__` JSON ReadyMag даёт всю карту страниц — sitemap не обязателен.

## Внешние зависимости текущего сайта

- ReadyMag CDN (`i-p.rmcdn.net`, `c-p.rmcdn.net`, `st-p.rmcdn1.net`) — пока живой. Если ReadyMag отключит проект, контент пропадёт.
- `lingvoeast.ru/f/ssap/*.pdf` — 10 PDF-каталогов проектов. Внешний домен. Надо зеркалировать в первую сессию работы.
- YouTube — 10 видео. Embed достаточно, скачивать не нужно.
- Instagram (2 аккаунта) и Smart Art — внешние ссылки.

## Риски сегодняшнего среза

- ReadyMag-проект помечен `is-exported=false` — это значит, что render идёт прямо с CDN ReadyMag. Платформа может отключить проект в любой момент.
- `lingvoeast.ru` отдаёт PDF по `http://`, не https. Если домен умрёт, каталоги пропадут.
- 600 MB PDF, скорее всего, сделан как растровый снапшот макетов ReadyMag, не как векторная вёрстка. Извлечь из него текст в чистом виде вряд ли получится — лучше OCR + сравнение с HTML.
