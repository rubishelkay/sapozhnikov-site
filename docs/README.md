## Короткий вывод

Сайт можно спарсить программно. ReadyMag отдает не только видимый HTML, но и большой JSON с метаданными проекта, списком страниц и ссылками на CDN-сниппеты. В этих сниппетах уже лежат тексты, ссылки, координаты виджетов, изображения и YouTube ID. На текущем срезе найдено 15 публичных страниц, 424 уникальных изображения с ReadyMag CDN и 10 уникальных YouTube-видео.

Для финального сайта лучше использовать парсер как миграционный инструмент: собрать тексты, структуру, ссылки, текущие превью-изображения и манифест ассетов, а затем заменить изображения на полнокачественные исходники.
