# SEO-подготовка, 3 ноября 2026

Рабочий проект: `sapozhnikov-site-2026/`. Отчет фиксирует проверки перед
публикацией. После локального просмотра владелец одобрил push в `main`
для автодеплоя тестового сайта. DNS и основной домен не переключаются.

## Выполнено

- 15 страниц используют исторические адреса ReadyMag.
- Семь временных адресов Astro и `/index/` перенаправляются одним 301.
- Меню, canonical, og:url и sitemap согласованы с основными адресами.
- Добавлены самостоятельные title и description для всех 15 страниц.
- Добавлены корректный robots.txt, исторический sitemap.xml и HTTP 404.
- noindex применяется к тестовым хостам через HTTP-заголовок, не к основному `.ru`.
- Подготовлен `.htaccess` для SpaceWeb/Apache.

## Тексты и внешний вид

Новые метаданные находятся в `src/data/seo.json`. Они основаны на существующих
заголовках, датах, подписях и текстах соответствующих страниц. Главная описывает
разделы портфолио; About перечисляет уже имеющиеся типы биографических сведений.
Место проживания, новые выставки и новые биографические факты не добавлены.

Title и description относятся к вкладке браузера, поисковой выдаче и превью ссылок;
это не новые видимые абзацы на страницах. Формулировки доступны владельцу для
проверки до публикации. Метаданные ReadyMag не копировались автоматически:
у его ретроспективы обнаружено описание другого проекта.

По отдельному требованию владельца сохранены заставка, задержки, видимое меню,
порядок фотографий, подписи и оформление. Дополнительной ссылки About нет.
Аудит структуры собранного HTML и CSS для всех 15 страниц подтвердил совпадение
видимой разметки, скриптов и правил стилей с предыдущей сборкой; исключение
сравнения касается только обновленных href меню и служебных CSS scope ID.

## Проверки

- `npm run check`: нет ошибок и предупреждений Astro.
- `npm run build`: статическая сборка, включая верхнеуровневый `404.html`.
- `npm run check:seo`: HTTP-проверки через локальный Cloudflare Pages / Wrangler.
- Тот же тест через локальный Apache с `.htaccess` (режим `--apache`).
- В браузере проверены меню на ширине 380 и серия A Wonderful Day на 380/1440.
- 15 страниц возвращают 200 и соответствующие метаданные.
- Алиасы с/без слеша сохраняют query-параметры и перенаправляют за один переход.
- robots и XML-карты корректны; карты перечисляют только 15 основных страниц.
- Произвольный и вложенный неизвестный путь возвращают 404 с noindex.
- Host-проверки: тестовые домены noindex, `.ru` без noindex.
- Все 424 различных локальных изображения, используемых в HTML, найдены;
  проверены их размеры, выборочные HTTP-ответы совпадают с исходными JPEG.

## Следующие отдельные задачи

- Полный визуальный разбор и индивидуальные alt для фотографий: текущие подписи
  сохранены, новые описания содержимого снимков не придумывались.
- Обновление биографии и списка выставок по материалам Сергея.
- Доступность меню без JavaScript и при reduced motion: отложена вместе с
  изменениями поведения заставки, согласно уточненному объему этой итерации.
- Проверка из российских сетей, доступ к Search Console / Яндекс Вебмастеру.
- После одобрения: публикация тестового домена, повторная HTTP-проверка;
  затем отдельно финальный хостинг и переключение основного домена.

Проверка Apache подтверждает работу конфигурации на локальной установке Apache;
на самом аккаунте SpaceWeb еще нужно проверить HTTPS, свободное место и поддержку
правил `.htaccess`. Управляемые Cloudflare правила robots добавляются на стороне
платформы: итоговый публичный ответ проверяется после публикации.
